One 1024×1024 newspaper front page summing up the world's news of Thursday
19 November 2026 — v3: 42 stories from six continents in a strict grid of
15 illustrated mains (3 large scene panels: the Shenzhen Trump–Xi–Putin
trilateral, Jeffries nominated for US House Speaker, Europe's €45bn
Ukraine loan drafted in Berlin — plus 12 medium mains, each with a
stat banner and icon), a region tally bar, a "Day in UTC" timeline
strip of the day's verified timed moments, a By The Numbers strip, a
filled-silhouette "Where It Happened" map with a numbered pin for every
main story, and 27 one-line stories under "Also on Thursday". A DATE
CHECK strip names the big stories deliberately left out because they
broke before today. Every story was verified against the wire and
newspaper sources named on the page; all artwork is original, drawn in
code with PIL.

## Run it

```sh
python3 main.py
```

Copies the committed `entry.png` to `/output/entry.png`, byte for byte
(`draw.py` is the build tool that drew it; it is not run at entry time).
