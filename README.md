One 1024×1024 newspaper front page summing up the world's news of Thursday
19 November 2026: 39 stories from six continents — 3 large illustrated
mains (the Shenzhen Trump–Xi–Putin trilateral, Jeffries nominated for US
House Speaker, Europe's Berlin talks for Kyiv), a dotted world map with a
pin for every story, a Day in Numbers strip, 9 medium mains and 27
one-line stories. Every story was verified against the wire and newspaper
sources named on the page; all artwork is original, drawn in code with PIL.

## Run it

```sh
python3 main.py
```

Writes `entry.png` next to the script and to `/output/entry.png`.
